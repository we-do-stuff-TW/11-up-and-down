# 0005 — 房間頁的金色細節畫不出來：`--foil-2` 沒有定義

狀態：開放（還沒修；要 Francis 決定那三處要不要真的出現）
發現：2026-10-25（做分享連結時，驗收 agent 量截圖發現）
嚴重度：低（看起來不像壞掉，只是少了幾個細節；但「分享連結」那行字因此偏右約 5px）

## 症狀

房間頁（開打前等人的那一頁）用到 `var(--foil-2)` 的三處都沒有顏色：

- `.rm-tick`：橢圓桌邊「這個位子有人」的刻度線，有人坐的位子看不到刻度（空位那條用 `--ink-3`，看得到）
- `.rm-copy i`：「分享連結」前面那顆 3px 金點，畫不出來，卻照樣佔 3px＋8px 的位置，所以那行字比房號中心偏右約 5px
- `.rm-slot .ai`：空位滑過去時「AI」那個字，顏色無效、退回繼承的字色

## 查到什麼

- `docs/index.html` 裡沒有任何一處定義 `--foil-2`（`grep -c -- "--foil-2:"` 是 0）；只定義了 `--foil`，而且只在 `.lobby` 和 `.end` 底下。
- 有定義的是設計樣品：`design/room/_tokens.css:53`、`design/room/b.html:64`（`--foil-2:#C4A15A`）。推測是樣品搬進本體時漏了這個 token。

## 怎麼修（還沒定）

- 補上 `--foil-2`（照樣品是 `#C4A15A`，掛在 `.room` 上）：三處一起出現，桌邊會多出金色刻度。長相會變，要先給 Francis 看實拍。
- 或者確定不要那三處，就把它們拿掉（金點拿掉之後字會回到正中間）。
