## 目標

一句話：對手剛出完、你一秒內就跟著出的時候，你那張牌不會憑空消失，也不會被一句錯的「這張牌不能出」打回來。

## 步驟

### A. 手機：先演的那一手要能自己重演（病 1）
- [x] A1. 出牌那一手的記錄帶著那張牌本身和「第幾局、第幾墩」：疊回去時牌不在手上就放回去再出一次。只在「同一局、同一墩、檯面上還沒有我」時放——那一列已經含著我那一手（realtime 比 HTTP 回話先到）時不准放，否則牌同時在手上和檯面上
- [x] A2. `net_test` 新劇本：對手廣播 → 我出（掛著）→ 對手那一列不帶手牌先到 → 我的牌要還在檯面上、手上少一張、不去問 state；再一條：含著我那一手的列先到 → 牌不准回到手上

### B. 伺服器：早到的那一手等前一家（病 2，候選「甲」）
- [x] B1. `index.ts` 的動作多一種答案 `wait`：「桌面還停在前一家，而這一手確實是你的（牌在你手上、這一墩你還沒出過；叫墩是還沒叫過）」。`step()` 遇到 `wait` 就隔一下重讀、再問一次，最多等 3 秒；等不到才 409。不算進提交輸了的 8 次
- [x] B2. 字分開：「還沒輪到你」（等不到前一家）與「這張牌不能出」（輪到你但牌不合規則／不在手上）。英文字典補一條
- [x] B3. `server_test` 新段：前一家晚 0.3 秒才出、我先到 → 兩張都要在桌上；前一家一直不出 → 3 秒左右回 409「還沒輪到你」；牌不在手上、這一墩出過 → 馬上 409、不等；依序叫墩、叫墩最後一家還在路上時莊家先出牌 → 都要寫得進去

### C. 手機：伺服器否決我那一手時帶回來的桌面要收（病 3）
- [x] C1. `fresher()`：同 rev 的列只在「它是伺服器否決我那一手的回話」時照收（對手的廣播、我那一手一起作廢）。比畫面舊的照樣不收
- [x] C2. `net_test` 新劇本：對手廣播 → 我出 → 409 帶同 rev 的真相 → 畫面要是真相（對手那張不在、輪對手、我的牌回手上）
