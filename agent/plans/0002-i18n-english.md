# 0002 — 全英文版本，設定裡可切換

**狀態**：完成（2026-09-14）
**目標（一句話）**：整個介面（牌桌／大廳／開房／設定／規則／收桌／登入頁／伺服器錯誤訊息）都有一份英文，
在「設定」頁多一排「語言 Language」可即時切換，選擇記在 `localStorage['ud.lang']`。

## 決策（已與 Francis 確認）

- **預設**：跟著瀏覽器。`navigator.language` 以 `zh` 開頭 → 中文，其餘 → 英文。使用者選過之後以他選的為準。
- **範圍**：`docs/index.html` 全部介面文字 + `docs/login.html` + 伺服器回來的錯誤訊息（用客端字典對照，
  **不改 edge function、不必重新 deploy**）。
- **程式碼註解不翻**：註解是寫給 Francis 看的。

## 做法

以「中文原文當 key」的字典，而不是另造一套語意 key。理由：原始碼裡留的還是看得懂的中文，
Francis 讀 diff 不用對照表；而且靜態 HTML 完全不用加 `data-i18n` 屬性。

三個零件（新的 `<script>` 塊，放在 supabase CDN 之前，掛在 `window` 上讓三個 script 塊 + module 都拿得到）：

1. `I18N.en` — 字典，`{ "中文原文": "English" }`。含 `%1` `%2` 佔位符給有變數的句子。
2. `T(zh, ...args)` — 英文模式查字典、查不到就原樣回傳中文；`%1` 依序代入 args。
   給「JS 裡組出來的句子」用（尤其是原本用 `+` 接成、英文語序不同的那些）。
3. `i18nDOM(root)` — 走訪 DOM 的文字節點與 `placeholder`／`aria-label`／`title`／`alt`／`content`，
   用同一份字典替換。第一次看到某個節點時把中文原文記進 WeakMap，所以來回切換不會走味。

`paint*()`／`render()` 尾端呼叫 `i18nDOM()`，動態畫出來的那一大片不用一處一處改；
只有「字串是用 `+` 接起來、英文得換語序」的地方才改寫成 `T("…%1…", n)`。

切語言時：寫 localStorage → 設 `<html lang>` → `i18nDOM(document.body)` → 重跑 `render()` 與目前這一頁的 paint。

## 步驟

1. i18n 核心（`T` / `i18nDOM` / `setLang` / 預設語言偵測）
2. 設定頁加一排「語言 Language」
3. 字典：靜態 HTML（頂列、大廳、開房、帳號／設定／規則、收桌）
4. 字典＋改寫：JS 動態字串（狀態列、座位牌、計分表、房間頁、規則說明、戰績、收桌）
5. 伺服器錯誤訊息對照（含 `找不到房號 XXXX` 這種帶變數的）
6. `docs/login.html` 同一套
7. 驗證：headless 兩種語言 × 2D／3D × 各頁截圖，掃有沒有漏掉的中文
8. HTML 展示給 Francis 看

## 之後要留意的

- **加新字串**：照常用中文寫在程式裡，再把那句中文當 key 加進字典。漏加不會壞（原樣顯示中文），
  但 `i18n_scan.ts` 會抓出來——所以改完介面順手跑一次。
- **測試的網址要帶 `?lang=zh`**：斷言寫的是中文文案，不釘住的話跑在英文語系的機器上會整批對不上。
- **兩個坑已經踩過**：
  - 主程式本來就有一個 `function T(str,x,y,size,o)`（牌面上那段字），會蓋掉 i18n 的 `T`，已改名 `TXT()`。
  - `renderHand()` 為了不打斷「按下與放開」有一層 `__keys` 快取，語言要一起算進 key，
    不然換語言時手牌的 `aria-label` 不會跟著換。
- **伺服器沒動**：edge function 回的錯誤訊息仍然是中文，在客端用同一份字典對照翻掉（`TErr()`）。
  以後在伺服器加新的錯誤訊息，記得也加進字典。
