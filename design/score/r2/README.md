# 計分表 · 第二輪

Francis 看完第一輪：**方向選 A（記分簿）**，但每一格的「拿／叫」不要——
只記得分失分，要乾淨。這一輪三案都照這個前提，以 A 的骨架為底。

那一刀比想像中重要：格子從 `3/3 +13` 縮成 `+13`，欄寬立刻夠用，
**第一輪 A 在 9–10 人時得把總分縮到 17px 的那個問題自己消失了**。
而且正負號本身已經說完「叫中沒中」（正分一定叫中、負分一定沒中），
所以綠色的點、hit/miss 的記號全部可以拿掉——這一輪只剩兩種顏色：一般的字，和紅色的負分。

    python3 ../shot.py "r2/shots/a@1440x900=a.html"    # shot.py 在上一層，PORT=8773

`_head.html` / `_tokens.css` / `_pips.svg` / `_data.js` 都共用上一層那份（同一場牌、同一組色票）。
這一層只多兩個共用檔：

- `_base.css` — 三案共同的骨架（表頭、局數欄、進行中那一列、人多時的分級）
- `_shared.js` — 局數欄的畫法、累計分數 `RUN`、表尾與自動捲到「現在」

## 三案

**甲 · 帳本**　只有數字。格子 19px、總分 Bodoni 34px、列高 41px。
那一局賺最多的人只把數字提亮一階，不加底也不加框。最少的東西、最大的字。

**乙 · 刻度**　骨架同甲，數字**底下**多一條軌：中線是零，得分往右長、失分往左長，長度＝分數。
整片看下來多一層地形。條要放在數字底下不是背後——壓在字上兩邊都看不清（試過，很糟）。
弱點要說清楚：這套計分是「10＋叫」，叫中幾乎都落在 +11～+15，沒中大多是 −1，
所以條主要分得出的是「中／沒中」，那件事顏色跟正負號已經講完了。它多給的其實是 +5（叫 0 中了）跟大失分那幾格。

**丙 · 累計**　每格兩排：上排小字是那一局的增減，下排大字是打完那局的累計。
頂上就不放總分了——最後有數字的那一列（標「現在」、整張表唯一亮的一列）就是現在的比數，
而且往上看得到是哪一局被超車的。表會自動捲到「現在」，總分永遠在視線裡。
人一多收掉上排，只留累計。

## 踩過的兩個坑（都會靜靜地壞掉）

1. **`const top = …` 在全域會 SyntaxError**。`window.top` 是不可設定的全域屬性，
   同名的 `let`/`const` 直接讓整支 script 不執行，畫面一片空白、也不會有紅字提示。改叫 `hiScore`。
2. **class 名撞到共用樣式**。丙本來把累計那一排叫 `.r`，結果 `_tokens.css` 的紅花色 pip 是
   `class="tsuit r"`、表尾右側是 `.ft .r`，兩邊一起被 `display:block` 打到——
   紅心紅方的 pip 掉到下一行、表尾的頁碼變成 19px。改叫 `.run`。
3. 附帶一條：各案都寫 `table.sc td{text-align:right}`，特異性比 `_base.css` 的 `td.gut` 高，
   局數欄會被拉成靠右。`_base.css` 那條要寫成 `table.sc td.gut` 才壓得住。
