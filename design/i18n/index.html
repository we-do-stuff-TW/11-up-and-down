全英文版 · 設定裡可切換

整個介面兩種語言：牌桌、大廳、開房頁、帳號／設定／規則、收桌、登入頁， 連伺服器回來的錯誤訊息都翻了（在客端對照，edge function 一行沒動、不必重新 deploy）。 預設跟著瀏覽器——navigator.language 是 zh 開頭給中文，其餘一律英文； 使用者在設定裡選過之後，以他選的為準（記在 localStorage['ud.lang']）。 底下每一組都是左中右英，同一站、同一刻、同一張牌局。

設定語言排在最前面——它管的是這一頁上其他每一排的字。兩個選項各自寫自己的語言，不會中文的人也認得出哪個是哪個

牌面的名字也翻：愛德華金邊 → Edwardian Gilt、賭場四色 → Casino Four-Colour、青花 → Blue Willow。 立體鏡頭那兩顆刻意不叫 Table——上面一排「牌桌」已經是 Table 了，所以是 The game ／ The study。 「畫質」那一排是立體牌桌後來加的（另一個 session 的 plan 0003），照同一套慣例進字典： 四個選項是 slug（自動／高／中／低 這種一個字的太容易撞），說明那句用 %1 帶「現在實際在跑哪一檔」。

牌桌頂列的數字、座位牌、狀態列、計分表

英文的單複數有做：「每人 1 張」是 EACH 1 card 不是 1 cards，「1 副」是 1 deck。 字典裡寫成 %1 %1{card|cards}，看第一個參數是不是 1。 讀螢幕的人聽到的牌名也換語序：中文是「紅心A」，英文是 Ace of Hearts——A/K/Q/J 念整個字，不是一個字母。

叫墩骰子那一排、最後一位的預告（剛好／欠幾／超幾）
規則整頁說明文字。夾著 <strong> 的長句是整塊換掉的，不是一段一段翻

計分那幾格、牌組那一句、叫墩方式那一段，都是照這一桌現在的規則即時算出來的， 兩種語言走的是同一個 roundPoints()——介面跟引擎不會各說各話。

開房頁座位表、房號、這一桌的規則
規則設定只有房主按得動的那一扇

全形標點在英文版換回半形：分數例子的「＋13」變 +13，選項之間的「／」變 /。 全形的寬度是為了跟中文的版面對齊，放在英文裡看起來像壞掉。

大廳四張空牌位、回剛才那一桌
登入頁這一頁排在設定之前，所以沒有切換鈕——跟著瀏覽器，或跟著這台裝置上次切過的語言

這一頁沒有搬整套 i18nDOM——只有八句話，自己帶一份小字典就夠了。 判斷語言的順序跟牌桌那邊一模一樣：?lang= → localStorage → 瀏覽器。 分享出去的卡片吃的那兩條 meta 也跟著換。

帳號戰績那一段
收桌台上三疊牌、誰贏了那一句
牌局中的設定多一顆「離開遊戲」，按第二下才真的走
來回切一趟切成另一種語言再切回來，畫面要跟沒切過一模一樣

每個節點第一次被翻譯時，中文原文記進一張 WeakMap，之後永遠拿原文去查字典。 不這樣做的話，切回中文時會拿英文去查字典、查不到、就卡在英文。

怎麼做的兩個 <script> 塊，都在 docs/index.html 裡
零件做什麼
I18N_EN字典。key 是中文原文，不是另造一套 t("lobby.join")——那種 key 讀 diff 什麼都看不出來。 短到會撞車的字（「中」「開」「關」「牌」「計分」）才用 slug，值寫成 {zh, en}。
T(zh, …)給 JS 組出來的句子。英文語序跟中文常常相反，所以那種句子不能用 + 接， 要整句丟進來配 %1 %2。
i18nDOM(root)走一遍 DOM 換文字節點與 aria-label／placeholder／title。 掛在 setHTML() 上——動態畫出來的 HTML 全部經過那裡，所以 paint 函式幾乎一行都不用改。
data-i18n句子中間夾著 <strong> 的（規則頁那幾段），文字節點會被切碎， 一段一段翻很難看。那種整塊 innerHTML 一次換掉。

要加一句新的字怎麼辦：照常用中文寫在程式裡，然後把那句中文當 key 加進字典。 沒加進去也不會壞——查不到就原樣顯示中文，底下那支掃描腳本會把它抓出來。

驗過了什麼deno run -A scripts/i18n_scan.ts
  • 殘留中文掃描。開 ?lang=en，把 12 站走一遍（大廳、設定、帳號、規則、開房、規則設定、 叫墩、出牌、來回切、牌局中的設定、收桌），每一站掃看得到的文字節點與四種屬性。 平面與立體各跑一次，0 筆殘留。
  • 反過來也掃。i18n_scan.ts zh 檢查中文版沒有跑出字典裡的英文（「the hook」是那條規則的名字，中文版也這樣寫，不算）。
  • 來回切那一趟是真的按下去的，不是重新開網址——?lang= 走的是開機那條路，設定頁那顆按鈕是另一條。
  • 既有六支測試全過（引擎 321 場、兩份規則 56,758 組、手指與畫面、連線時序、收桌、登入簽章）。 測試的網址現在都帶 ?lang=zh——斷言寫的是中文文案，不釘住的話跑在英文語系的機器上會整批對不上。
